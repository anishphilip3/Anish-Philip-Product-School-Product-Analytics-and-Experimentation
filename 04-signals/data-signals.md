# The Signals · FinWise

> Module 4 · Data & Analytics. The data pattern you found and the indicators you'll steer by.

## The data pattern

Across 13 months of FinWise data, five metrics revealed three distinct patterns:

| Metric | Pattern | What it shows |
|---|---|---|
| Trial-to-Paid Conversion | **Ceiling** | Flat at 1.87–2.08% for 13 months — a structural cap |
| Import Usage % | **Ceiling** | ~40% plateau — the gateway to the North Star is stuck |
| Modeling Usage % | **Growth** | The one metric rising — 31% toward 58% |
| Avg Session Duration | **Cliff** | Sharp mid-2024 drop from ~14 to ~5 min |
| Sessions / User | **Slow Leak** | U-shaped — dropped to 3, then recovered to ~9 |

**The uncomfortable finding:** Modeling Usage nearly doubled (index 100 → 187) while conversion never moved (r ≈ 0.24, not significant, r² ≈ 0.06). The 2% cap is **structural** — a pricing/paywall/packaging problem, not an activation-depth problem. This split the strategy into two experiments: (A) lift Import Usage to grow the pool, and (B) restructure pricing to break the ceiling.

_____

## Leading indicators

- **Import Usage %** (Get-Started) — stuck at a ~40% ceiling, the gateway to the North Star. This is the dial Experiment A (sample-data on-ramp) targets.
- **Modeling Usage %** — the Aha metric, already growing organically.

_____

## Lagging indicators

- **Trial-to-Paid Conversion** — the primary outcome, stuck at ~2%.
- **NDR / ARR growth** — earned by lifting activation → conversion + retention.
- **1-Year Retention** — currently 40% (60% churn).

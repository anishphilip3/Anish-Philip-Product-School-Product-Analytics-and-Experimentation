# FinWise — Product Analytics & Experimentation Strategy

_A complete, evidence-backed experimentation strategy for **FinWise Co.**, a product-led, reverse-trial SaaS for small-business financial management. Built one deliverable per module._

> **Anish Philip · Product Experimentation · Jun 2026**

---

## The Story (growth thesis)

> **FinWise's problem isn't acquisition — it's a leaky post-signup funnel.** Trial users arrive, but few reach value and fewer stay. The strategy: get more users to their **first modeling output** (activation), turn that into a **weekly habit**, and unlock **multi-seat collaboration** for lock-in — while treating the stuck **2% trial→paid conversion as a structural pricing problem**, not an activation-depth one.

Every module below is one move in that strategy, and each is backed by the FinWise data, not opinion.

## The through-line

**Bet** (the leak is conversion + retention, not acquisition) → **Solution** (get users to the Aha faster) → **Mechanic** (make the value a weekly habit) → **Signals** (the data says the 2% is a *structural ceiling*) → **Validation** (test the activation on-ramp; read results honestly) → **Model** (fix the pricing ceiling the signals exposed). Each piece hands the next its reason to exist.

## 1 friction · 1 Aha · takeaways

- **One friction.** I kept reaching for pricing as the fix. The data forced me to see it was an activation problem first — the connect-a-bank wall was the real friction. Pricing came after, and only because the data proved the 2% was structural.
- **One Aha.** Realizing the 2% conversion number was a symptom, not the disease. When modeling usage nearly doubled and conversion didn't budge, the funnel diagnosis changed my entire strategy.
- **Takeaways.** Experimentation is a system, not a tactic. Stage before method. Model follows value. The read date set up front, and knowing when NOT to change the price, were the lessons that stuck.

## Key numbers (FinWise, from the M1 dataset)

- Trial→Paid conversion: **~2%** (flat across 13 months) · ARR **$10M** · One-year retention **40%** (60% churn)
- 13-month funnel: **94,558 visits → 6,424 trials → 128 paid**

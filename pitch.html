Strategy · M1

The growth bet

Hypothesis

The core belief

If we add an in-trial milestone guiding users to FinWise's core value action (connect data → first modelling output), then trial→paid conversion rises ~1–2pp (from 2% toward 3–4%), because a 2% rate means most users never hit the Aha moment before the paywall.

The bet

Collaboration growth loop

Bet on a Collaboration growth loop, not acquisition. Make FinWise multiplayer: owner invites accountant → they manage books together → more seats join → FinWise becomes the system of record → upgrades → each collaborator seeds a new workspace. Deliberately NOT doing Content or Referral loops — those feed a top of funnel that already doesn't convert.

Activation · M2

The Aha moment

A user connects their data and sees their first personalized financial snapshot — one plain-language insight about their money. Not a feature: a realization. It predicts retention because financial visibility is a recurring need.
Onboarding prototype

Sample-data on-ramp

Five screens, three to value: Welcome → Connect (bank or sample data) → Snapshot ✨ (the Aha) → Invite → Success. Value first, asks later — one job per screen.

Retention · M3

The habit mechanic

Mechanic

"Money Momentum"

Trigger: weekly notification. Action: open FinWise → review snapshot → act on ≥1 insight. Reward: deeper financial reports that unlock at milestones (4wk: Monthly Trend, 12wk: Quarterly Forecast, 52wk: Year in Review).

A grace week auto-banks monthly — miss a week, no reset. Rejected leaderboards (privacy violation) and points (extrinsic decay). Works via loss aversion, owner identity, and goal gradient.

Why forgiving

No punishing streaks

Hard streaks cause anxiety and rage-quits. A finance tool using that pattern feels manipulative. Grace weeks protect months of built habit.

Metrics · M4

The signals

Leading indicators

What we move

Import Usage % (Get-Started) — stuck at a ~40% ceiling, the gateway to the North Star. This is the dial the sample-data on-ramp targets.

Modelling Usage % — the Aha metric, already growing organically.

Lagging indicators

What we prove

Trial→Paid conversion (~2%, flat 13 months)

1-year retention (40%, 60% churn)

NDR / ARR growth

The data pattern

The 2% ceiling is structural

Modelling Usage nearly doubled (index 100 → 187) while conversion never moved (r ≈ 0.24, not significant). The 2% ceiling is structural — a pricing/paywall problem, not activation-depth. This split the strategy: (A) lift Import Usage to grow the pool, (B) restructure pricing to break the ceiling.

Experiment · M5

The validation

A/B Test · 50/50 Split
Method A/B test — clean per-user randomization, 50/50 split. Chosen over MAB (no scarce-conversion pressure), Holdout (signal in first session), Geo-Test (no marketplace effects), Switchback (no temporal carry-over).
Hypothesis If we add an "Explore with sample data" path on the Get-Started screen, then more trial users reach their first modelling output. Primary metric: % reaching first modelling output within 7 days. Success: significant (p < 0.05), ≥5pp absolute lift.
Guardrail Trial→paid conversion must not significantly drop.
Read date ~6 weeks, pre-set — no peeking.
Monetization · M6

The model

Stage 2 Revenue Expansion Freemium (Reverse-Trial)
Recommendation

Reverse-trial freemium

Move trial → reverse-trial freemium. Day 1–14: full premium. Day 15+: permanent free tier (import + basic modeling). Paywall at the feature boundary, not a time boundary. Validates 'packaging matched to value.' Targets Get-Started Import Usage % (stuck at ~40%).

Supporting signal

Cluster at the boundary

Conversions should cluster tightly at the paywall boundary, not scatter. ARPU must not decline. Free-tier users must show higher Import Usage % than current trial users. Cohort-based test, read at 8 weeks.

Reflection · The Story

What I learned

Biggest friction

The hard part

I kept reaching for pricing as the fix. The data forced me to see it was an activation problem first — the connect-a-bank wall was the real friction. Pricing came after, and only because the data proved the 2% was structural.

Key Aha moment

When it clicked

Realizing the 2% conversion number was a symptom, not the disease. When modelling usage nearly doubled and conversion didn't budge, the funnel diagnosis changed my entire strategy — from "fix activation depth" to "fix the paywall."

Course takeaways

What stuck

Experimentation is a system, not a tactic. Stage before method. Model follows value. The read date set up front, and knowing when NOT to change the price, were the lessons that stuck. Every module handed the next its reason to exist.

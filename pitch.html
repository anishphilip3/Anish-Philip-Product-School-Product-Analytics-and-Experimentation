Strategy · M1

The growth bet

Hypothesis

The core belief

If we add an in-trial milestone guiding users to FinWise's core value action (connect data → first modeling output), then trial→paid conversion rises ~1–2pp (from 2% toward 3–4%), because a 2% rate means most users never hit the Aha moment before the paywall.
The bet

Collaboration growth loop

Bet on activation and collaboration, not acquisition. Make FinWise multiplayer: owner invites accountant → they manage books together → more seats join → FinWise becomes system of record → upgrades → each collaborator seeds a new workspace. The loop restarts with a bigger base.
Activation · M2

The Aha moment

Aha moment

When value lands

A user connects their data and sees their first personalized financial snapshot — one plain-language insight about their money. Not a feature: a realization. It predicts retention because financial visibility is a recurring need.
The solution

Sample-data on-ramp

Only ~39% of trial users ever import data. We added an "Explore with sample data" path so users reach a modeling output immediately — value first, asks later. Five screens, three to value: Welcome → Connect (bank or sample) → Snapshot ✨ (the Aha) → Invite → Success.
Retention · M3

The habit mechanic

Mechanic

"Money Momentum" — forgiving weekly streak

A weekly habit loop: open FinWise → review snapshot → act on ≥1 insight. Rewards are deeper financial reports that unlock at milestones (4-week: Monthly Trend, 12-week: Quarterly Forecast, 52-week: Year in Review). A grace week auto-banks monthly — miss a week, no reset, no guilt. Matches the weekly cadence of financial activity. Rejected leaderboards (privacy) and points (extrinsic decay).
Metrics · M4

The signals

Leading

Import Usage %

Stuck at a ~40% ceiling — the gateway to the North Star. This is the dial the sample-data on-ramp targets. Modeling Usage % (the Aha metric) is already growing organically.
Lagging

Trial→Paid conversion; 1-year retention

Conversion flat at ~2% for 13 months. 1-year retention at 40% (60% churn). NDR/ARR growth earned by lifting activation → conversion + retention.
Data pattern

The 2% is structural

Modeling Usage nearly doubled (index 100 → 187) while conversion never moved (r ≈ 0.24, not significant). The 2% ceiling is a pricing/paywall problem, not an activation-depth problem. This split the strategy into two experiments: grow the pool (M5) and break the ceiling (M6).
Experiment · M5

The validation

Method

A/B test — 50/50 split

Clean per-user randomization. Chosen over MAB (no scarce-conversion pressure), Holdout (signal appears in first session), Geo-Test (no marketplace effects), and Switchback (no temporal carry-over).
Hypothesis

Sample-data on-ramp lifts activation

If we add an "Explore with sample data" path on the Get-Started screen, then more trial users reach their first modeling output. Primary metric: % reaching first modeling output within 7 days. Success: significant (p < 0.05), ≥5pp absolute lift.
Guardrails

Conversion + read date

Guardrail: trial→paid conversion must not significantly drop. Read date: ~6 weeks, pre-set — no peeking. If successful: ship → Holdout → pricing experiment (M6). If not: instrument Get-Started to find the true drop-off.
Monetization · M6

The model

Stage 2 Revenue Expansion · Freemium (Reverse-Trial)
Recommendation

Reverse-trial freemium

Move from a time-limited trial to a reverse-trial freemium model. Day 1–14: full premium access. Day 15+: permanent free tier (import + basic modeling). The paywall sits at the feature boundary, not a time boundary — users upgrade because they need more. Targets Get-Started Import Usage % (stuck at ~40%).
Model signal

Cluster at the boundary

Conversions should cluster tightly at the paywall boundary (where users outgrow basic modeling), not scatter. ARPU must not decline. Free-tier users must show higher Import Usage % than current trial users. Cohort-based test, read at 8 weeks.
Reflection · The Story

What I learned

Friction

The hard part

I kept reaching for pricing as the fix. The data forced me to see it was an activation problem first — the connect-a-bank wall was the real friction. Pricing came after, and only because the data proved the 2% was structural.
Aha

The moment it clicked

Realizing the 2% conversion number was a symptom, not the disease. When modeling usage nearly doubled and conversion didn't budge, the funnel diagnosis changed my entire strategy — from "fix activation depth" to "fix the paywall."
Takeaways

What stuck

Experimentation is a system, not a tactic. Stage before method. Model follows value. The read date set up front, and knowing when NOT to change the price, were the lessons that stuck. Every module handed the next its reason to exist.

## The Aha moment (definition)

The moment a trial user **connects their financial data and sees their first personalized snapshot** — one plain-language insight about their money (e.g., "cash-flow positive: +$6,200 last month; software spend up 32%"). It's a *realization* ("I can finally see my business's money at a glance"), not a feature.

**Why it predicts retention:** the behavioral signal is *connected data + viewed first insight in session 1*. Financial visibility is a recurring need, so a user who reaches it has a built-in reason to return — the flip side of the 2% conversion / 40% retention leak.

## The prototype (5 screens, 3 to value)

1. **Welcome + goal** — one tap: cash flow / where money goes / profit (personalizes the path)
2. **Connect data** — connect a bank **or "Explore with sample data"** (the friction-killer)
3. **✨ Financial snapshot — the AHA** — a personalized headline insight + one surprising callout
4. **Invite** — post-Aha, seeds the Module 1 collaboration loop
5. **Success** — sets the return habit

## Rationale

Built on **one job per screen** and **value before asks**: it moves a brand-new user from a single goal tap → a low-friction data connection (with a sample-data escape hatch) → a personalized snapshot in three screens, then only *afterward* asks them to invite a collaborator. The **Aha is Screen 3** — the instant FinWise turns raw data into a plain-language insight, because that realization is what gives an owner a reason to come back.

**The one friction removed:** the connect-a-real-bank wall before any value — the sample-data path lets users hit the Aha first, making the real-data connection a value-driven choice rather than a blind cost.

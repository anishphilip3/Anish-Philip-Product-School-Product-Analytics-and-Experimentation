# The Model · FinWise

> Module 6 · Pricing & Monetization. The pricing & packaging recommendation memo for FinWise.

## Stage + model

**Stage 2: Revenue Expansion** — $10M ARR proves value creation (Stage 1) is done. The 2% conversion ceiling is structural (M4 evidence), so the model and paywall placement are the levers.

**Model: Freemium (Reverse-Trial)** — chosen over Subscription (time pressure forces decisions before value is felt — the status quo problem), Transaction (financial management is continuous, not discrete), and Advertising (trust is the currency in fintech; ads undermine it).

_____

## Recommendation

Move from a time-limited trial to a **reverse-trial freemium** model:
- **Day 1–14:** full premium access — every new user experiences forecasting, consolidation, and team features
- **Day 15+:** drop to a permanent free tier (import + basic modeling stay free forever)
- **The paywall:** sits at the feature boundary, not a time boundary — users upgrade because they need more, not because a clock ran out

**The bet it validates:** packaging matched to value. Watch for conversion clustering at the feature boundary — if conversions cluster tightly, scale; if diffuse, iterate the boundary, not the price.

**Target indicator:** Get-Started Import Usage % (M4 Leading 1, stuck at ~40%). Removing the time wall lets more users cross the activation threshold.

_____

## Model signal

Conversions should **cluster tightly at the paywall boundary** (the point where users outgrow basic modeling), not scatter. ARPU must not decline. Free-tier users must show higher Import Usage % than current trial users at the same tenure. Validated via cohort-based test, read at 8 weeks.
